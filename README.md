## Keterbatasan

- Ini **snapshot tampilan**, bukan aplikasi yang berfungsi. Form dan tombol tidak memproses data.
- Data yang tampil adalah data contoh hasil pengujian. Jangan dipakai untuk menyimpan data pelanggan sungguhan.
- Aplikasi penuh dengan login, Prisma/SQLite, upload bukti bayar, verifikasi pembayaran, dan API membutuhkan hosting Node (Vercel/Render/Railway).
